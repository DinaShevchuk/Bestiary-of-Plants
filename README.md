# Flora — Бестиарий растений

**Тип проекта:** учебный веб-проект, frontend-прототип справочника растений с диалоговым интерфейсом.  
**Текущий этап:** статический frontend с демонстрационной панелью администратора.  
**Версия:** 1.1

## О проекте

Flora — веб-интерфейс справочника необычных и интересных видов растений. Целевой сценарий продукта предполагает, что пользователь вводит название растения или задаёт вопрос на естественном языке, а система находит подходящие документы и показывает краткий ответ с источниками.

На текущем этапе реализована визуальная и интерактивная часть frontend. Чат является **статическим демонстрационным**: он показывает примеры диалогов, принимает сообщения и отвечает заранее подготовленными фразами. Backend, BM25, RAG и LLM в этой версии не подключены.

## Что реализовано

- Основная страница чата: список диалогов, создание нового чата, отправка сообщений и демонстрационные ответы.
- Формы входа и регистрации с клиентской проверкой полей.
- Светлая и тёмная темы оформления.
- Панель администратора (`admin.html`): обзор, список пользователей, каталог растений, история демонстрационных чатов и описание проекта.
- Добавление, редактирование, поиск, блокировка и удаление демонстрационных пользователей.
- Добавление, редактирование, поиск и удаление демонстрационных карточек растений.
- Локальное сохранение данных панели в `localStorage`.

## Ограничения прототипа

- Вход и регистрация не выполняют реальную серверную аутентификацию.
- Панель администратора не защищена серверной проверкой роли и доступна по прямому адресу.
- Пользователи и растения в панели — демонстрационные записи; изменения хранятся только в текущем браузере.
- История чатов не сохраняется на сервере.
- Чат не подключён к интеллектуальному поиску, корпусу документов или языковой модели.

Панель и чат предназначены для демонстрации frontend-сценариев, а не для эксплуатации с реальными пользовательскими данными.

## Запуск

Требуется Python 3 (или любой другой локальный HTTP-сервер). Из корневой папки проекта выполните:

```bash
python -m http.server 8000
```

Откройте в браузере:

- Главная страница: `http://localhost:8000/`
- Панель администратора: `http://localhost:8000/admin.html`
- Вход: `http://localhost:8000/login.html`
- Регистрация: `http://localhost:8000/register.html`

## Проверка административной панели

1. Откройте `admin.html`.
2. В разделе «Пользователи» добавьте тестовую запись, измените её, заблокируйте и удалите.
3. В разделе «Каталог растений» добавьте и отредактируйте карточку.
4. Обновите страницу и убедитесь, что изменения остались в браузере.
5. Проверьте поиск, навигацию, переключение темы и отображение на узком экране.
6. Для сброса демонстрационных данных удалите ключи `flora-admin-users` и `flora-admin-plants` из `localStorage`.

Подробности и ограничения приведены в `docs/frontend/admin-panel.md`.
