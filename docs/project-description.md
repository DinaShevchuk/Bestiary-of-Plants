# Описание проекта «Бестиарий растений» (Flora)

## 1. Общая характеристика

«Бестиарий растений» (Flora) — учебный веб-проект, цель которого — предоставить пользователю удобный интерфейс для знакомства с необычными и интересными видами растений. Целевой сценарий продукта предполагает поиск по названию растения или вопросу, сформулированному на естественном языке, и получение краткой справочной информации с указанием источников.

## 2. Цель и задачи

**Цель:** спроектировать и постепенно реализовать веб-сервис, упрощающий поиск и изучение сведений о растениях.

**Задачи проекта:**

1. Разработать понятный пользовательский интерфейс.
2. Предусмотреть диалоговый сценарий взаимодействия с информационной системой.
3. Подготовить структурированный корпус документов о растениях.
4. Реализовать поиск релевантных документов, в первой версии — BM25.
5. Предусмотреть формирование ответа на основе найденных материалов и отображение источников.
6. Предусмотреть административное управление пользователями и содержимым каталога.
7. Документировать архитектуру, требования, интерфейс и проверки качества.

## 3. Целевая аудитория

Пользователи, которым нужен справочный материал о растениях: учащиеся, любители ботаники и посетители, желающие быстро найти базовую информацию о конкретном виде. Сервис не предназначен для постановки медицинских диагнозов, лечения или определения безопасности употребления неизвестных растений.

## 4. Основные роли

- **Гость / пользователь:** открывает чат, формулирует вопрос и просматривает демонстрационный диалог. После подключения backend роль пользователя сможет получать доступ к предусмотренным функциям поиска.
- **Администратор:** в целевой версии управляет пользователями и справочным содержимым. В текущем frontend представлен демонстрационной панелью без серверной авторизации.

## 5. Функциональные возможности текущего frontend

- Страница чата со списком примеров диалогов.
- Создание нового локального диалога и отправка сообщений.
- Демонстрационные ответы, выбираемые из заранее заданного набора.
- Формы входа и регистрации с проверкой формата введённых значений.
- Переключение светлой и тёмной темы.
- Панель администратора с демонстрационным управлением пользователями и каталогом растений.

## 6. Ограничения текущей версии

Текущая версия — статический frontend-прототип. Вход и регистрация не проверяют данные на сервере и не создают реальные учётные записи. Чат не обращается к BM25, backend, RAG или LLM. Административные изменения сохраняются только в `localStorage` конкретного браузера. Поэтому демонстрационные данные и операции не следует считать полноценным серверным функционалом.

## 7. Планируемое развитие

Следующий этап предполагает подключение backend API, базы данных пользователей и растений, защищённой авторизации с ролями, поискового индекса BM25, генерации ответов на основе найденных документов, списка реальных источников и серверного хранения истории запросов.

## 8. Ожидаемый результат

Итоговый продукт должен предоставлять удобный справочный интерфейс, возвращать ответы, связанные с проверяемыми документами корпуса, корректно сообщать о недостатке информации и предоставлять администратору инструменты безопасного управления данными.
