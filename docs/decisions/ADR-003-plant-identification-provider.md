# ADR-003: Фотоидентификация через внешний Pl@ntNet API

- **Статус:** принято; интеграционный путь реализован, live-проверка требует API key.
- **Контекст:** собственное обучение классификатора потребовало бы курирования датасета, разметки и отдельного цикла оценки; это не обязательно для первой версии справочника.
- **Решение:** браузер отправляет JPEG/PNG в backend; backend проксирует изображение к Pl@ntNet, возвращает ранжированный список видов, а пользователь подтверждает кандидата. После выбора система использует внутренний BM25/RAG для ответа из корпуса проекта.
- **Последствия:** не требуется обучение собственной модели; для сервиса необходим внешний ключ и сеть. Внешний сервис может не распознать растение или вернуть несколько близких видов.
- **Ограничения:** результат — кандидат, а не безусловно достоверное определение; внутренний ответ ограничен локальным корпусом. API недоступен без `PLANTNET_API_KEY`.
- **Отказ/альтернатива:** фотофункция выключена, если ключ не задан; текстовый поиск и RAG продолжают работать.
