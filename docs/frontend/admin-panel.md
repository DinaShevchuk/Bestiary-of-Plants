# Панель администратора Flora

## Назначение

`admin.html` — демонстрационный интерфейс административной части frontend-проекта «Бестиарий растений». Он показывает предполагаемые рабочие места администратора и позволяет проверить базовые сценарии управления данными без backend.

## Разделы интерфейса

- **Обзор:** сводные счётчики пользователей и записей каталога, состояние прототипа и быстрые переходы.
- **Пользователи:** просмотр, поиск, добавление, редактирование, блокировка/разблокировка и удаление демонстрационных учётных записей.
- **Каталог растений:** просмотр, поиск, добавление, редактирование и удаление демонстрационных карточек растений.
- **История чатов:** таблица примеров диалогов, встроенных в `js/app.js`.
- **О проекте:** краткое описание назначения, реализованных и планируемых функций.

## Хранение данных

Списки пользователей и растений сохраняются в `localStorage` браузера под ключами `flora-admin-users` и `flora-admin-plants`. При первом открытии используются демонстрационные начальные записи. Кнопка действий изменяет только локальные данные текущего браузера.

## Ограничения и безопасность

- Это frontend-макет, а не защищённая административная система.
- Роль администратора не проверяется сервером; переход на `admin.html` доступен по прямому адресу.
- Пароли не создаются и не хранятся панелью; нельзя использовать этот прототип для реальных пользователей.
- Данные `localStorage` можно изменить через инструменты разработчика браузера и они не синхронизируются между устройствами.
- Для промышленной версии необходимы backend-аутентификация, серверная проверка роли и прав на каждую операцию, API управления пользователями и каталогом, журналирование и серверная база данных.

## Проверка вручную

1. Открыть `admin.html` через локальный HTTP-сервер.
2. Перейти в раздел «Пользователи», найти запись, добавить новую, отредактировать её, заблокировать и удалить тестовую запись.
3. Перейти в «Каталог растений», добавить карточку, изменить описание и удалить её.
4. Обновить страницу и проверить, что пользователи и растения сохранились в том же браузере.
5. Проверить поиск, навигацию по разделам, мобильную ширину и переключение темы.
6. Очистить `localStorage` для сброса демонстрационных записей к начальным значениям.
