# Текущее состояние frontend

## Страницы

| Файл | Назначение | Реализованное поведение |
|---|---|---|
| `index.html` | Основной интерфейс чата | Список демонстрационных диалогов, создание чата, отправка сообщения и ответ по заранее заданному циклу шаблонов |
| `login.html` | Экран входа | Клиентская проверка формата полей; успешная проверка показывает уведомление и перенаправляет в чат |
| `register.html` | Экран регистрации | Клиентская проверка имени, логина и пароля; успешная проверка показывает уведомление и перенаправляет в чат |
| `admin.html` | Панель администратора | Демонстрационные операции с пользователями и карточками растений через `localStorage`, обзор, список примеров чатов и описание проекта |

## Статический чат — важное уточнение

В текущей версии чат является **статическим демонстрационным интерфейсом**. В `js/app.js` заданы примеры диалогов и массив `BOT_REPLIES`; после отправки пользовательского сообщения приложение через задержку выбирает очередной заранее подготовленный ответ. Запросы на backend не отправляются. Поиск BM25, RAG, LLM, загрузка изображений, реальные источники и сохранение переписки на сервере не реализованы.

Следовательно, корректная формулировка для демонстрации: «Интерфейс чата и сценарий обмена сообщениями представлены в виде статического прототипа; интеллектуальный поиск и генерация ответов относятся к следующему этапу».

## Общие элементы

- Светлая и тёмная темы с сохранением выбора в `localStorage`.
- Общие стили расположены в `css/style.css`.
- Клиентская логика чата и форм авторизации находится в `js/app.js`.
- Логика административной панели находится в `js/admin.js`.
- Изображения оформления находятся в `img/`.

## Запуск

Из корневой папки проекта:

```bash
python -m http.server 8000
```

Открыть `http://localhost:8000/`. Для работы демонстрационных функций не требуется backend. Запуск через HTTP-сервер предпочтительнее прямого открытия HTML-файла.
