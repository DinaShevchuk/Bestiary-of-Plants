# Существующие интерфейсные артефакты

## 1. HTML-страница и связанные ресурсы

- **Главная страница:** `index.html`.
- **Стили:** `css/style.css`.
- **Логика:** `js/app.js`.
- **Графика:** `img/`.
- **Backend serving:** FastAPI отдаёт корневую страницу и папки `/css`, `/js`, `/img`, поэтому приложение и `/api/v1/*` работают с одного origin.
- **Статус:** существующий дизайн сохранён; чат подключён к API, история сообщений хранится в `localStorage` текущего браузера.

На главной странице есть: переключение темы, список/создание чатов, ввод вопроса, кнопка загрузки фото, предпросмотр, отображение кандидатов распознавания, загрузка/ошибка ответа, источники и backend status.

## 2. Макет Figma

- **Статус:** в исходной документации указано, что макет уже существует.
- **Ссылка:** URL Figma в предоставленном архиве не найден; не добавляйте вымышленный адрес. Команда может вписать фактический URL вручную.

## 3. Сверка HTML и API

- `POST /api/v1/ask` — сообщения пользователя и ответы/источники.
- `POST /api/v1/identify` — распознавание фотографии, если настроен PlantNet.
- `GET /api/v1/config` — статус подключённого backend, LLM и фотоидентификации.
- Список чатов и история сохраняются в browser `localStorage`; серверной синхронизации пока нет.
- Вход/регистрация остаются демонстрационными страницами, реальная аутентификация отсутствует.

Проверка: `python -m uvicorn backend.app.main:app --reload --host 127.0.0.1 --port 8000`; затем откройте `http://127.0.0.1:8000/`.
