# Definition of Done для AI-изменений

## Для любой задачи

- [ ] Изменение связано с требованием/сценарием или новое требование добавлено в SDD.
- [ ] Текущая архитектура и код исследованы; незатронутая функциональность не переписана.
- [ ] Секреты, реальные API keys и персональные данные не попали в исходники.
- [ ] Документация синхронизирована с кодом и фактическим статусом.
- [ ] Выполнены релевантные тесты либо прямо указано, почему они недоступны.

## BM25 / RAG

- [ ] Corpus schema и source metadata сохранены.
- [ ] Изменение BM25/chunking/threshold проверено на том же benchmark.
- [ ] BM25 score не называется вероятностью.
- [ ] LLM получает retrieved context, а не только user question.
- [ ] При отсутствии контекста система отказывается от ответа.
- [ ] Source refs соответствуют фрагментам, реально переданным модели.

## Agentic RAG

- [ ] Только backend allowlist tools; произвольный SQL/URL/файловый доступ не добавлен.
- [ ] Максимум вызовов и размер контекста ограничены на сервере.
- [ ] Дубликаты chunks не раздувают context.
- [ ] Tool outputs помечены source refs; данные документов считаются недоверенными.
- [ ] Тестируется завершение цикла при достижении лимита.

## LLM/API

- [ ] Конфигурация провайдера, timeout и обработка ошибок описаны.
- [ ] Ключ хранится только в `.env`.
- [ ] Live provider не заявляется проверенным без фактического запроса.

## Фотоидентификация

- [ ] Поддерживаемые типы/размеры файлов ограничены и проверяются.
- [ ] Кандидаты обозначены как предварительные; score не трактуется как гарантия.
- [ ] Пользователь подтверждает вид до retrieval.
- [ ] Нельзя использовать результат для определения съедобности/безопасности.

## Интерфейс

- [ ] Пустой запрос, loading, успешный ответ, отсутствие сведений и API error обработаны.
- [ ] Источники строятся из API metadata и не содержат придуманных ссылок.
- [ ] UI остаётся доступным с клавиатуры и адаптивным.
- [ ] История localStorage не выдаётся за серверное хранение.
